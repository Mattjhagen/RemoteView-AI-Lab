01 · Start here

A simple idea, tested carefully

Remote viewing is the idea of describing something without seeing it or receiving ordinary clues. This lab records descriptions before revealing a hidden reference, then lets a judge compare them. It is a practice and comparison tool, not a demonstration that remote viewing works.

Two ways to participate

Human sessions: you write the impressions; AI can ask neutral follow-up questions.
AI experiments: the model writes a single speculative description; you or another person judge it later.

Start with one human session to learn the flow, or use the AI walkthrough below. No special vocabulary or prior experience is needed.

02 · Hidden targets

What stays hidden, and why

A target is the reference scene assigned to a trial. It stays hidden while impressions are being recorded. This avoids shaping a description to fit an answer you already know.

The current lab uses a small, reusable pool of five bundled landscape illustrations. Blind judging shows all five in shuffled order, with one assigned target and four alternatives. Repeated use can make the scenes familiar, so avoid deliberate guessing from memory. Familiarity limits what the results can tell you.

A sealed record is locked against later edits. Its SHA-256 hash is a digital fingerprint of the recorded text, not evidence of unusual perception.

03 · Human walkthrough

Your first human session

  1. Choose Human sessions → + New session. The lab assigns a hidden target and displays a session code. The code is a label, not a clue.
  2. Write what comes to mind. For example: “cool, rough surface; a curved edge; open space above.” This is invented sample wording, not a target hint. Use your own words.
  3. Press Record impression. Typing alone does not save it. Add more observations if you wish. Ask for guidance offers neutral prompts; it does not identify the target.
  4. Choose Finalize transcript. Record or clear unsaved text first. Confirm only when finished: finalization permanently locks the transcript.
  5. For a scored trial, choose Blind judge this session before revealing. Open the judging link or share it privately with an independent judge who can sign in. Only your observations, not AI monitor questions, appear there.
  6. Submit the blind ranking, then reveal. Once judging starts, reveal is blocked until the ranking is submitted. Download transcript saves a copy after finalization.

You can also reveal a finalized session directly for personal reflection. Once revealed, it cannot start blind judging and does not become a scored dashboard trial.

04 · AI walkthrough

Run one AI trial

  1. Open Model settings. Select an installed, available model and press Save model. The same selected model is used for human guidance and AI experiments.
  2. Choose AI experiments. For a first run, leave the condition at Target selected before inference and temperature at 0.7. Leave the seed blank to have one assigned.
  3. Keep the default Experimental Instructions. They request speculative sensory-style impressions. You can edit them for new trials, but never add target clues. Switching conditions restores the default instructions.
  4. Press Run AI experiment once. “Inference” simply means the model generating its response. It may take about 45 seconds. If a request times out, refresh history before retrying: a result may already have been saved.
  5. Read the saved status. A completed trial seals the output and provides Open blind judging. An invalid or failed trial has no ranking to submit.
  6. Judge, then check Dashboard. Submit all five ranks to score the trial. Reopen its entry in Experiment history to inspect the recorded settings, prompts, timestamps and hashes.

05 · Conditions & settings

Change one thing at a time

Target selected before inference
The reference is selected and saved before generation begins. The model still receives no target information.
Target selected after inference
The model response is generated and fingerprinted first, then an independent reference is selected. “After” changes selection timing, not when you view the result.
Neutral control · imagined scene
The default user instruction asks for an imagined scene. An independent reference is selected after generation, then judged in the same way. This helps compare ordinary scene generation with hidden-target instructions.
Temperature (0–2)
Controls variation in model word choices. Lower values generally produce more predictable text; higher values generally allow more variation. It does not measure accuracy or paranormal sensitivity. Start at 0.7 and keep it fixed for a planned comparison.
Inference seed (optional)
A number that helps control model sampling. Blank means the lab assigns a number and records it. It never selects the target. The same seed does not guarantee identical output across different models, prompts, versions or execution environments.

Example plan: decide in advance to run the same number of before, after and control trials with one model and fixed settings. Keep every outcome and report invalid and failed runs too. Changing prompts or settings after seeing results makes comparisons harder to interpret.

06 · What the AI sees

Speculative text, with a clear boundary

In an AI experiment, the model receives the selected model configuration, system and user instructions, temperature and seed. The app does not send the hidden target, candidate images, target descriptions or identifying information to that generation request.

In a human session, the AI monitor uses the conversation to offer neutral questions. It has no access to the target. The human participant supplies the observations.

The output is generated language, not a live view, camera feed or verified perception of a hidden scene. A vivid or confident description does not establish that the model perceived anything. Custom instructions can break the intended blind setup if you put clues in them. Local administrators are trusted; this is not a separate, tamper-proof target vault.

07 · Blind judging

Rank matches from 1 to 5

A blind judge compares the sealed observations with five candidate images without knowing which is assigned. Prefer someone who has not seen the answer and was not coached toward a match.

  1. Read the entire sealed description before choosing.
  2. Compare every candidate, including mismatches. Use the same approach for every trial.
  3. Assign 1 to the best match, then 2, 3, 4 and 5 to the weakest match. These are positions, not ratings out of five. Use each number exactly once; no ties.
  4. For example, candidates A–E might receive ranks 3, 1, 5, 2, 4. B is your first choice. These letters are just an example.
  5. Press Submit final ranking. Submission is permanent; the assigned target is shown afterward.

A hit means the assigned target was ranked first. Every other first choice is a miss, even if the target ranked second or shared some features. The judge is a person; this workflow does not ask the AI to rank its own answer.

08 · Reading results

Why the baseline is 20%

There is one assigned target among five candidates. If selection is uniform and your first choice carries no information about that assignment, the probability of a first-place hit is 1 in 5, or 20%.

This is a long-run expectation, not a quota. Ten trials do not have to contain exactly two hits. For example, three hits from ten scored trials is 30% accuracy; that alone does not show an effect beyond chance.

The dashboard shows descriptive 95% Wilson confidence intervals: ranges expressing uncertainty in the estimated hit rate under the statistical model. Small samples usually leave substantial uncertainty. An interval above 20% is not by itself proof: repeated comparisons, selective reporting, familiar images, self-judging and clues can distort the picture.

Keep the conclusion modest

Report all planned trials, sample sizes, conditions and exclusions. Look for repeatable results with fresh targets and independent judging. These results do not prove paranormal abilities, AI consciousness, awareness, or access to hidden information.

09 · Dashboard

Know what each count means

Scored trials / First-place accuracy
Only submitted blind rankings count. Accuracy is first-place hits divided by scored trials, combining eligible human and AI trials.
Awaiting judging
Assignments created but not yet submitted. These are not misses.
Completed AI trials
Usable, sealed outputs; they still need submitted judging to count toward accuracy.
Invalid / Failed / Running AI trials
Separate technical or response states, not scored hits or misses.
Cumulative first-place accuracy
The running hit rate in ranking-submission order, with a 20% reference line.
Group comparisons
Human versus AI, models and conditions, with trial counts and 95% intervals. Unequal samples and differing settings can make comparisons misleading.
Scored trial history
Submitted rankings and their outcomes. Times are shown in UTC. Press Refresh results after judging in another tab.

A dash means no scored estimate yet, not 0%. History belongs to this browser’s private owner session, not a shared account-wide total. Another browser or cleared cookies may show different history without deleting stored records.

10 · Questions & troubleshooting

Common points of confusion

Why did the AI refuse, or explain that it cannot see?

Some models respond with a capability disclaimer despite the experimental instructions. The lab’s automatic, text-based screening marks refusals, empty or malformed replies and insufficiently descriptive output as invalid_response. Screening is imperfect and checks usability, not truth or accuracy. The raw response is preserved, but the trial is excluded from judging and accuracy.

Is an invalid response the same as a miss?

No. A miss is a usable trial whose assigned target was not ranked first. Invalid responses are excluded; failed means generation encountered a technical problem. Report exclusions alongside scored results so they do not disappear from your interpretation.

Why can’t I reveal or change my ranking?

Finalization locks observations. Starting blind judging blocks human target reveal until submission. Submitted rankings and completed experiment records stay locked so results cannot be rewritten after seeing the answer.

Does “before” mean the AI sees the target first?

No. It describes when the server selects the hidden reference. Neither before nor after supplies target information to the AI.

Why are there pictures if the AI never sees them?

The images are for the human judge’s comparison after the output is sealed. Seeing candidates during judging is expected; knowing the assigned answer before ranking would spoil the blind comparison.

My model is unavailable, or a request failed. What next?

Refresh Model settings, select an available model and save it. For a timeout, check history before running again. A recorded failed or invalid trial stays in history; a new run creates a separate trial.

Can someone else judge my trial?

Yes. Share the Open blind judging link privately. They need access to the site and its sign-in gate as well as the link. The link identifies the assignment, so treat it as private. An independent judge should not know the answer.

Does a striking match prove remote viewing or consciousness?

No. Broad descriptions can fit multiple scenes, and coincidences happen. This lab records comparisons; it does not determine whether a human or model has paranormal abilities or whether an AI is conscious.
